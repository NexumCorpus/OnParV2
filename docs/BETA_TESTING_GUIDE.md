# OnPar Beta Testing Guide

Welcome to the OnPar beta testing program! Thank you for helping us build the best inventory management system for small restaurants.

## 🎯 What We're Testing

OnPar is designed to help small restaurants reduce food waste by 10-20% through smart inventory management and alerts. During this beta, we want to validate:

- **Core functionality** works reliably for real restaurant operations
- **User experience** is intuitive and efficient for busy kitchen staff
- **Alert system** provides timely and actionable notifications
- **Value proposition** delivers measurable cost savings

## 🚀 Getting Started

### 1. Sign Up & Onboarding
1. Visit the application and create your account
2. Complete the setup wizard:
   - Enter your restaurant name and monthly food budget
   - Configure alert settings (defaults are fine to start)
   - Add initial inventory items (try the CSV import with sample data)
   - Add menu items with estimated sales/waste percentages

### 2. Daily Usage
- **Add inventory items** as you receive deliveries
- **Update quantities** as you use ingredients
- **Monitor alerts** for low stock and expiring items
- **Track menu performance** and adjust waste percentages

## 🧪 Key Areas to Test

### Core Functionality
- [ ] **User Registration & Login** - Test sign-up and sign-in flows
- [ ] **Inventory Management** - Add, edit, delete inventory items
- [ ] **Menu Tracking** - Add menu items and track performance
- [ ] **Alert System** - Verify you receive email alerts for:
  - Low stock items (below reorder point)
  - Items expiring within 7 days
  - Budget overspend (90% of monthly budget)
- [ ] **Profile Settings** - Update restaurant info and alert preferences
- [ ] **CSV Import** - Test bulk import of inventory data

### User Experience
- [ ] **Mobile Responsiveness** - Test on phone, tablet, desktop
- [ ] **Navigation** - Ensure all menus and links work correctly
- [ ] **Performance** - Note any slow loading or laggy interactions
- [ ] **Error Handling** - Try invalid inputs and edge cases

### Business Value
- [ ] **Cost Tracking** - Monitor if the app helps identify waste
- [ ] **Time Savings** - Compare to your current inventory method
- [ ] **Alert Usefulness** - Are notifications timely and actionable?

## 📊 Test Scenarios

### Scenario 1: New Restaurant Setup
1. Sign up as a new restaurant
2. Complete onboarding with realistic data
3. Import inventory using CSV (try the sample data)
4. Set up 5-10 menu items with realistic percentages
5. Navigate through all dashboard sections

### Scenario 2: Daily Operations
1. Add new inventory items (simulate receiving delivery)
2. Update quantities (simulate using ingredients)
3. Create items with low stock to trigger alerts
4. Add items with near expiry dates
5. Check that email alerts are received

### Scenario 3: Budget Management
1. Set a monthly budget in your profile
2. Add enough inventory to approach 90% of budget
3. Verify budget alert is triggered
4. Test budget tracking accuracy

### Scenario 4: Menu Optimization
1. Add menu items with varying waste percentages
2. Identify high-waste items in the dashboard
3. Test editing menu items and updating percentages
4. Review insights in the alerts panel

## 💡 Beta Testing Tips

### Data Entry Tips
- **Use realistic data** from your actual restaurant
- **Test edge cases** like very high/low quantities
- **Try different units** (kg, lbs, liters, pieces, etc.)
- **Test with and without expiry dates**

### Alert Testing
- **Set low reorder points** to trigger alerts quickly
- **Use near-future expiry dates** to test expiry alerts
- **Adjust budget** to test overspend notifications

### Mobile Testing
- **Test on your phone** during actual kitchen work
- **Try landscape and portrait** orientations
- **Test with poor internet** connection
